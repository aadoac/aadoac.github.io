Classes in Java

Introduction

Object-oriented programming (OOP) is a programming paradigm, the first programming language to introduce this paradigm was Simula in the 1960s, but it got popularity in the 80s and 90s with Objective-C and C++. This new paradigm introduced the class concept, it is a template in programming for creating objects which are the instances of a class.

In this article we're going to explain the concept of class in Java and the different kinds of classes in Java.

Type of Classes

As we said, a class is a template to create an object. For example Student can be a class with properties like name, gender, age... and methods like getName, getGender, getAge... and Olivia is an object of this class, where she's a real student and the properties will have values like name: Olivia, gender: female, age: 15... and the same methods as the class.

There're different kind of classes in Java,

  • Concrete class.- It's the regular class. It can be instantiated and provide full implementation of the methods.
  • Abstract class.- It's a class declared with abstract keyword. These classes can't be instantiated.
  • Final class.- It's a class that can't be subclassed.
  • Nested class.- Java allows you to define a class within another class. It's called a nested class. There're two categories of nested classes: Non-static nested classes are called inner classes, and nested classes that are declared static are called static nested classes.
  • Local class.- It's a class defined in a block, normally local classes are defined inside of a method.
  • Anonymous class.- It's like a local class but without name. It enables you to declare and instantiate a class at the same time. It helps you to make the code more concise.

The Anatomy of a Java Class

A Java class normally contains three components: fields, constructors, and methods.

  • Fields.- Or attributes, it represents the properties that an object holds.
  • Constructors.- It's a special method used to initialize a new object. It has the same name as the class.
  • Methods.- These are the actions an object can perform.
